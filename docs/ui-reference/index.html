Owner review task

このreferenceは、実装のpixel仕様ではありません。通常reviewer画面はコメント確認用です。FHD表示は「公開プレビュー」で確認します。30秒taskで、表示中MODのlocal状態、evidence state、次actionを確認できることを検証します。

30秒task

  1. 表示中のMODがinstalledか確認する。
  2. enabled状態とversion stateを確認する。
  3. Observed、Unknown、Needs reviewを区別する。
  4. 次に開くread actionを選ぶ。

Trust boundary

selectionだけではpage、identity、writeを変更しません。
writeはpreview、差分、rollback、explicit approvalを経由します。
